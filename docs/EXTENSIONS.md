# Evoxup Membership extensions

The WordPress.org build bundles its required infrastructure modules inside Evoxup Membership. They are part of the same release and update together with Core.

Separately distributed executable add-ons are **not** downloaded, installed, updated, rolled back, activated, deactivated, or deleted by Evoxup Membership. Install or manage such add-ons through the normal WordPress **Plugins** workflow or the instructions supplied with that separate add-on.

The optional Evoxup package catalog may display metadata for free or commercial external packages. A license or membership may describe eligibility for a separately distributed commercial package or genuine external service, but it never unlocks functionality included in the WordPress.org Evoxup Membership plugin.

Non-executable data owned by Evoxup Membership uses WordPress APIs and the uploads directory when filesystem storage is required.
